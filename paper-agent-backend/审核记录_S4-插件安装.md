| # | 现象 | 根因（源码级） | 修复 |
|---|---|---|---|
| 1 | `trust` 失败 `E_PACKAGE_TRUST`（"does not meet the required trust policy"） | `packages/package-manager/src/trust-gate.ts` 要求 `entry.license` ∈ `LICENSE_ALLOWLIST`（MIT/Apache-2.0/BSD-*/ISC/0BSD/MPL-2.0/Unlicense）；我们的 `package.json` **缺 license 字段**（预览里那句 "license information is unavailable" 就是它） | 补 `"license": "MIT"` → trust 通过 |
| 2 | `enable` 失败 `E_PACKAGE_STATE`，daemon 日志 `extension.failed code=E_TOOLDEF_META` | `packages/extension-api/src/tool.ts` 的 `checkToolMeta`：`replay` 仅接受 `safe｜never｜idempotent`（我写了 `conditional`）；`costHint` 仅接受 `{credits?,wallMs?}` 有限数值（我写了 `{kind:'compute'}`） | 改为 `replay:'safe'/'never'` + `costHint:{wallMs:10000}`/undefined → enable 通过 |
| 3 | daemon 之后无法启动（`child exited before readiness`） | 前一步 install 在 50% 失败留下 `.agnes-fetch-*` 未完成源码获取；`staging.ts:recoverStaging` 刻意**不自动清理**（"never infer that an unfinished external command has stopped"），daemon 因此拒绝启动 | **可逆**改名隔离（未删除）该残留 → AGH 自动清理 stage 目录 → daemon 恢复 |

> 附带改进：`verify-offline.mjs` 原只校验"meta 八键齐全"，**未校验取值合法性**，因此没能提前发现 #2。
